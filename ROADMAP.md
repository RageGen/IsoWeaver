# Roadmap

1. Make delete, rename, and new-folder changes visible immediately; fix selection status and folder-tree ordering.
2. Expand safety tests for path parsing, extraction failures, and rebuild failures.
3. Validate BIOS, UEFI, and hybrid boot preservation with redistributable fixtures.
4. Move host-folder enumeration off the GTK thread and add cancellation and measurable progress where possible.
5. Add sorting, undo, recent images, and collapsible folder navigation.
6. Separate session, GTK, and extraction code into focused modules as needed.
7. Validate portable packaging on clean Linux distributions before publishing releases.
