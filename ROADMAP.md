# Roadmap

1. Add automated validation for path parsing, extraction safety, transaction failures, and xorriso operations.
2. Move GTK actions, session state, and ISO backend code into smaller modules with explicit capabilities.
3. Add worker-thread execution, progress, cancellation, recent images, tabs, search, sorting, and undo.
4. Add nested directory navigation and in-image destination paths for additions.
5. Add read-only raw-image partition inspection and supported filesystem extraction.
6. Validate boot preservation against BIOS, UEFI, and hybrid ISO fixtures; package for Ubuntu.
